# LegalEase website photos: prompts for ChatGPT

Paste each prompt into ChatGPT, download the picture, and save it in
**public/images** (Next.js version) or the **images** folder next to index.html (single-file version) with the exact file name shown.
The site picks each photo up automatically once the file is there (refresh the page).

All prompts share the same look so the photos match each other and the white and blue site.
